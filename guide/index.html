iPhone の Safari

ショートカットで、画面の内容ごと保存

共有ボタンから「Hikidashi に保存」を選ぶだけ。タイトル、画像、投稿者、pixiv のタグなど、開いているページに表示された内容を読み取って、追加の確認画面を開きます。

  • ログインが必要なページや、画面をブラウザの中で組み立てるサイト（React など）でも読めます
  • 読み取りは Safari の中だけ。外部には何も送りません
  1. ショートカットを追加する。 iPhone でこのボタンを開いて、「ショートカットを追加」をタップ。
    Hikidashi に保存を入手
  2. スクリプトの実行を許可する。 「設定 → ショートカット → 詳細」で、「スクリプトの実行を許可」をオンにします（最初の 1 回だけ）。
  3. 保存したいページで、共有する。 Safari でページを開き、共有ボタン →「Hikidashi に保存」をタップ。
  4. 内容を確かめて、追加する。 Hikidashi が開くので、確認して保存します。
共有の一覧に「Hikidashi に保存」が出ない

共有シートを一番下までスクロールして、「アクションを編集」を開き、「Hikidashi に保存」をオンにしてください。

押しても、何も起きない／エラーになる
  • 「設定 → ショートカット → 詳細」で「スクリプトの実行を許可」がオンか確認します。
  • Hikidashi が入っているか（最新版か）確認します。
  • ページが読み込み終わってから、もう一度試します。
アプリの共有ボタン

X・YouTube・pixiv などから、ひと手間で

共有ボタンから「Save to Hikidashi」を選ぶと、そのページの URL から、タイトル・サムネイル・作者・本文を取得して保存できます。

  • 保存の前に、画像の候補から選び直したり、カテゴリやメモを編集したりできます
  • X の投稿は、本文がメモに入ります。メモの #ハッシュタグ をタップすると、その言葉で検索できます
  1. 共有ボタンを押す。 X、YouTube、pixiv、ブラウザなどで、保存したいものの共有ボタンをタップ。
  2. 「Save to Hikidashi」を選ぶ。 一覧の中から、アプリのアイコンをタップします。
  3. 確認して「保存」。 取得した内容を確かめて、必要なら直してから、保存します。
共有の一覧に出てこない

共有シートの一番右の「その他」を開き、「Save to Hikidashi」をオンにしてください。お気に入りに入れておくと、上の方に出ます。

画像が取れなかった／違う画像になった

保存の前に、画像の候補から選び直せます。URL を直接入れることもできます。サイトによっては、画像が見つからないことがあります（画像なしでも保存できます）。

PC の Chrome

ページを QR にして、iPhone で読み取る

PC で見ているページを QR コードにして、iPhone のカメラで読み取るだけで保存できる拡張機能です。サーバーもアカウントも要りません。

  • タイトル・サムネイル・作者・本文を自動で取得（YouTube と X は専用の取り方、pixiv はタグも）
  • 画像の候補から選べて、QR にする前に、内容を編集できます
  • 外部には何も送りません（権限は、クリックしたタブの読み取りだけ）
  1. 拡張機能を入れる。 GitHub から最新版を入手して、Chrome に読み込みます。入れ方は、GitHub のページに書いてあります。
    最新版をダウンロード入れ方を見る
  2. 保存したいページで、アイコンをクリック。 内容が表示され、QR コードが出ます。
  3. iPhone のカメラで QR を読み取る。 Hikidashi が開き、追加の確認画面が出ます。
CSV

CSV で、出し入れする

ほかのアプリやサービスから移るときも、CSV を作れば、そのまま取り込めます。書き出した CSV は、バックアップにも使えます。

  1. 設定を開く。 Hikidashi の「設定」タブへ。
  2. 「CSV をインポート」で読み込む。 書き出しは「CSV をエクスポート」。フォルダを選ぶと、自動で書き出すこともできます（頻度も選べます）。
列の形式。 先頭の行に、見出しを書きます。クリエイターは、| で区切って、複数指定できます。日本語の見出しも使えます。

よくある質問

データは、どこに保存されますか？

iPhone の中だけです。アカウントも、サーバーも、広告もありません。CSV を書き出して、バックアップできます。

機種変更するときは？

「CSV をエクスポート」で書き出して、新しい iPhone の Hikidashi で「CSV をインポート」します。自動書き出しを設定しておくと、フォルダ（iCloud Drive など）に、最新の CSV が残ります。

人に画面を見せるとき、見られたくない作品は？

「プライベート保護」で、ルールに当てはまる作品を、一覧・検索・ランダムから外せます。見たいときだけ、Face ID で一時的にオフにできます（アプリを離れると元に戻ります）。アプリ切り替え画面を、ぼかしたり黒くしたりする設定もあります。
